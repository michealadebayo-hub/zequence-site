Checkout FAQ

Before you request a pack.

Do I pay immediately on this page?

No. This page captures your request so Zequence can issue the correct invoice or secure payment link for the selected pack.

What is the refund position?

Digital template files are usually non-refundable after delivery. If there is a delivery issue or wrong pack selection, contact Zequence before using the file so it can be corrected.

Can I share the workbook with my team?

Yes, for internal business use within the buying organisation. Resale, redistribution, public sharing, or uploading into a template marketplace is not included.

How do custom builds start?

Custom work starts with a scope review, data request pack, agreed deliverables, and project timeline. Sensitive finance files should be shared only through an agreed secure channel.
